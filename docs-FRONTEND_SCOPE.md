# Alcance funcional - Frontend v0.1

## Entrega parcial

La Web Application debe demostrar que el backend no es únicamente una colección de endpoints. La interfaz consolida el estado del sistema y permite completar los casos principales de AgroLeak.

### Incluido ahora

| Módulo | Capacidad |
|---|---|
| Dashboard | Estado consolidado por dispositivo |
| Telemetría | Lecturas e histórico básico |
| Alertas | Consulta, severidad y resolución |
| Válvula | OPEN/CLOSE y confirmación simulada |
| Plagas | Consulta de observaciones externas/simuladas |
| Demo | Escenarios Normal, Leak y Obstruction |

### Deliberadamente posterior

Autenticación, administración multiusuario, tiempo real, configuración de umbrales, mapas, reportes y visión artificial real.
